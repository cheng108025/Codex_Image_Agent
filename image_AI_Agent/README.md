# image_AI_Agent

一包完整的「文字 → 指定畫風角色插畫」agent。輸入中文角色描述 + 風格編號,
agent 自動翻成英文提示詞並生成該風格的插畫(角色 + 該風格專屬背景)。
20 種風格彼此一眼可分。

## 內容

| 檔案 | 角色 |
| :--- | :--- |
| `AI_AGENT.md` | **AI_AGENT** — 工作流：中文輸入 → 翻譯 → 組提示詞 → 生成 |
| `styles.md`   | **SKILL** — 20 種風格模組 + 共通正/負向提示詞 + 差異化機制 |

## 怎麼用

把這包放到有圖像生成工具的 agent(如 Codex)能讀到的位置,然後：

```text
角色描述：10歲、霧棕色捲髮、金色眼睛、憂鬱表情、王族服裝
風格編號：18
```

agent 依 `AI_AGENT.md` 流程：翻成英文 → 查 `styles.md` 第 18 號模組 → 組出
完整英文 POSITIVE/NEGATIVE → 生成該風格插畫。

## 每個風格怎麼確保「不一樣」

`styles.md` 每個模組都寫足三件事,這是風格互不撞的關鍵：

1. **造型/比例重塑句** — 不只換材質,連形狀與比例語言都重塑(新藝術=流線長形、立體主義=多視角切面、工筆重彩=細線雅緻比例)。
2. **鄰居互斥負向詞** — 擋掉最容易被誤畫成的鄰居(新藝術擋裝飾藝術、黑色電影擋賽博龐克、包浩斯擋歐普藝術)。
3. **專屬簽名背景** — 每個風格配一個強化自身識別、且互不重複的背景。

## 去背模式(可選)

預設生成「角色 + 風格背景」的完整插畫。若要純去背透明素材,在輸入註明「去背」,
agent 會改用純色去背背景、移除簽名背景並檢查 Alpha(詳見 `AI_AGENT.md`)。

## 擴充風格

在 `styles.md` 末尾 append,套四欄結構(編號｜名稱｜正向模組｜負向模組),
每個新風格務必寫足上述三件事(造型重塑 + 專屬背景 + 鄰居互斥)。
