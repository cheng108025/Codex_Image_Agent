# AI_AGENT — 中文角色描述 → 英文提示詞 → 指定風格插畫

這是一個完整 agent 工作流。使用者用**中文**描述角色 + 指定風格編號,
agent 負責：①翻成精準英文 ②從 SKILL(`styles.md`)組出英文正/負向提示詞 ③生成該風格插畫。
每種風格是一次完整的視覺再詮釋(造型、比例、線條、上色、光線、材質、**專屬背景**),不是套濾鏡。

## 使用者輸入(中文即可)

```text
角色描述：{中文角色描述}
風格編號：{STYLE_ID}         # 01–20,對照 styles.md
構圖：{FRAMING}              # 可省略,預設完整全身
姿勢：{POSE}                # 可省略,預設自然站姿
```

## 單次生成政策（最高優先）

- 使用者每次提出一次生圖要求，最多呼叫圖像工具一次，只生成一張插畫。
- 生成後立即呈現並停止。完成後檢查只能回報問題，不得自動修改、重生、補生備選圖或第二張。
- 只有使用者看過圖片後明確表示不滿意、要求修改或重生，才可再生成一張；生成後再次停止。

## 執行流程

1. **翻譯**：把中文角色描述精準翻成英文 `{CHARACTER_DESCRIPTION}`,逐項保留每個
   識別特徵(髮色/髮型、眼睛、服裝、配件、年齡、體型、表情),不新增重大元素、不刪細節。
2. **讀 SKILL**：讀 `styles.md`,取共通正/負向提示詞 + `{STYLE_ID}` 對應的風格正/負向模組。
3. **組裝英文提示詞組並先展示給使用者確認**(見下方輸出格式)：
   - POSITIVE = 共通正向 + 風格正向,填入 `{CHARACTER_DESCRIPTION}`、`{FRAMING}`、`{POSE}`。
     風格正向已內含該風格的**專屬簽名背景**與造型重塑句,照用即可。
   - NEGATIVE = 共通負向 + 風格負向(含鄰居互斥詞,用來擋畫成別的風格)。
4. **生成插畫**：用當前 agent 的圖像工具生成「角色 + 該風格專屬背景」的完整插畫。
   只依英文描述建角色,不沿用任何舊圖或既有角色。
5. **完成後檢查並回報（不得自動重生）**：
   - 角色描述吻合、識別特徵齊全。
   - 風格辨識度：造型/材質確實重塑,不是同一張動漫臉套濾鏡。
   - 背景是該風格的專屬背景,不是通用雪花圓框、也不是空白。
   - 角色是畫面主體、完整落在畫布內、無浮水印。
6. **停止等待**：呈現唯一一張結果。使用者明確要求修改後,才依回饋再生成一張。

> 當前 agent 若沒有圖像生成工具,執行到步驟 3 交付英文提示詞組即可,並註明
> 「生成需在具圖像工具的 agent(如 Codex)執行」。
>
> **去背模式(可選)**：若使用者要純去背透明素材,改在提示詞加
> `on a flat solid #00ff00 chroma-key background, no scenery, no signature background`
> (角色含綠色改 `#ff00ff`),並移除風格模組的簽名背景句;生成後移除背景、檢查 Alpha。

## 輸出格式(步驟 3 交付給使用者)

```text
風格：{STYLE_ID}｜{風格中文名}

【POSITIVE】
{完整英文正向提示詞}

【NEGATIVE】
{完整英文負向提示詞}
```

完整規則、共通提示詞、20 種風格模組全文見同目錄 `styles.md`。
