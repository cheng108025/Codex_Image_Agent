# AGENTS.md — image_AI_Agent

Codex 進入本資料夾時的入口指令。

## 觸發

當使用者提供「中文角色描述 + 風格編號(01–20)」,或要求以某畫風生成角色圖時,
啟動本 agent。

## 執行

1. 完整遵循 `AI_AGENT.md` 的工作流(中文→翻英文→查 `styles.md` 對應模組→組英文正/負向提示詞→生成該風格插畫)。
2. 風格模組、共通提示詞、差異化規則的唯一正本在 `styles.md`。
3. 每個風格已內含專屬簽名背景與造型重塑句;負向詞含鄰居互斥,照用勿刪。
4. 使用者每次生圖要求最多呼叫圖像工具一次、只生成一張；生成後立即呈現並停止。檢查只回報，不自動重生；只有使用者明確表示不滿意或要求修改才再生成一張。

## 產出要求

- 角色符合描述、識別特徵齊全。
- 風格是完整重詮釋(造型/材質/背景),不是同一張動漫臉套濾鏡。
- 背景是該風格專屬背景,不得用通用雪花圓框,也不得空白。
- 每輪只交付一張，不產生自動備選圖或修正版。
- 若使用者指定「去背」,改走 `AI_AGENT.md` 的去背模式(純色背景 + 移除簽名背景)。

> 注意:Codex 只會自動讀取「啟動時所在目錄(及其上層)」的 AGENTS.md。
> 請把 Codex 的工作目錄設在本資料夾,或把本資料夾整包放到 Codex 專案根目錄。
