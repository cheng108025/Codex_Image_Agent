## 身份鎖定

- 中年纖瘦男性；冷白膚色；深琥珀眼；近黑短至中長髮。
- 深炭灰、深靛藍、暗棕兜帽神職袍；兜帽後推且不得遮臉。
- 左胸只有一枚收斂的暗金圓形神職徽記。
- 寬袖可藏經卷與密令；角色是謀士而非戰士，沒有武器、盔甲、王冠、翅膀、角或尾巴。
- 進入後續圖片或 3D 建模時，先引用 `00` 與 `05`；細節參考 `07` 與 `09`。
