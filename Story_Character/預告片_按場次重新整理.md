這份整理怎麼看 

·  **「一場」的判定：**同一時間、同一地點、角色持續互動且事件未中斷，才合併為一場。地點或戲劇目標改變，就拆成下一場。 

·  **出場角色：**只列實際在鏡頭空間中的人物；只被回憶、提及或用聲音出現者，另列為「場景外角色／聲音」。 

·  **LINE：**以台詞、呼吸、表情和安靜構成的鏡頭，負責交代資訊或深化人物。 

·  **MOMENT：**戰鬥、奔跑、崩塌、犧牲、力量爆發等動態畫面，負責節奏、震撼與反差。 

·  **資訊控制：**預告片不需要把事件說完整。每場最後都標出哪些真相應該保留，避免劇透或失去懸念。

SCENE 00｜舊日赫克托：用英雄祭建立王國與奧德里奇的形象 

**補敘場／開端資訊場** 

|     |     |
| --- | --- |
| **時間／地點** | 聖曆1581年，泰倫中央區與王國宮殿・英雄祭前後 |
| **實際出場角色** | 童年克里茲、班尼迪克、泰倫居民、教會信徒、工人；奧德里奇以肖像、雕像、壁畫或旁白出現 |
| **場景外角色／聲音** | 高文、葛洛莉雅可作短暫生活鏡頭；奧德里奇不必真人現身 |
| **預告片節奏** | LINE＋少量建立世界觀的 MOMENTS |

這一幕發生什麼 

·  以泰倫繁華街道、王國旗幟、英靈廳、英雄聖喬治壁畫與建國十週年準備，讓觀眾先相信赫克托曾經是穩定而強盛的王國。 

·  班尼迪克或群眾的旁白介紹奧德里奇：他是赫克托的創國君主，也是所有人認為不會敗亡的王。 

·  鏡頭最後可停在年幼克里茲仰望父親肖像或王座，暗示這個孩子日後將被迫接下遠超過自己的責任。 

可用台詞 

**班尼迪克／旁白：**「奧德里奇國王已征服莫德地區，很快便會回到泰倫。」 

**旁白建議：**「那時的赫克托，沒有人相信它會迎來覆滅的一天。」 

可拆成的畫面／鏡頭 

·  泰倫全景：白金宮殿、教堂尖塔、旗幟與街道上的慶典裝飾。 

·  英靈廳內，克里茲站在巨大王像或空王座前，人物顯得很小。 

·  金色歡慶畫面突然被低沉戰鼓切斷，接帕拉諾雅軍逼近泰倫。 

**預告片功能：**只負責交代「赫克托曾經強盛、奧德里奇曾經不可戰勝、克里茲是王子」。不要在這一場塞入太多角色關係。 

**資訊控制／備註：**此場屬於把你原本抽象的「介紹帝國」具體化；可以使用小說現有英雄祭素材，不必另外設計一大段歷史戰爭。

SCENE 01｜皇后寢房：屠城聲中，母親要求克里茲殺死她 

**★★★ 序幕核心／亦可作預告片尾聲** 

|     |     |
| --- | --- |
| **時間／地點** | 現在時間線，泰倫王宮・皇后寢房；宮外正發生政變與屠殺 |
| **實際出場角色** | 克里茲、皇后阿格妮絲 |
| **場景外角色／聲音** | 宮外帕拉諾雅軍、逃難者與士兵只以聲音、火光、震動存在；克里茲的「理性人格」可用內心聲音呈現 |
| **預告片節奏** | 極靜 LINE，外面以高噪音 MOMENTS 反襯 |

這一幕發生什麼 

·  克里茲單膝跪在華美卻不斷震動的寢房裡，想帶母親逃走。皇后先因過往創傷顫抖，隨後突然平靜地要求兒子殺死她。 

·  皇后稱克里茲為帶來不幸的「惡魔之子」。克里茲的理性人格逼迫他放棄兒子的情感，以王的身分做出決定。 

·  若使用完整版本，克里茲最後刺殺母親，伏在她身上，讓她的手碰觸自己的臉，說出「媽媽，晚安」。預告片可以在揮劍前切黑，不揭露結果。 

可用台詞 

**皇后：**「把我殺了……」 

**皇后：**「絕對不能，再生出像你這樣招來不幸的……惡魔之子……」 

**內心聲音：**「你是「王」。放下你那自私低賤的慾望，拋下你那幼稚無用的情感。」 

**內心聲音：**「做出身為「王」，你該做出的選擇。把眼前的女人殺了。」 

**克里茲：**「再給我幾分鐘吧。就把這當作是……我作為孩子，最後的任性。」 

**克里茲：**「媽媽，晚安。」 

可拆成的畫面／鏡頭 

·  第一人稱或過肩鏡頭：皇后蜷縮在床上，燭台因爆炸震動。 

·  克里茲嘴唇上的乾血、握劍發白的指節、皇后空洞的金色眼睛。 

·  外面屠城聲突然被抽掉，只剩耳鳴與呼吸聲；劍尖抬起後切黑。 

**預告片功能：**用母親的描述替主人公定義：「他是王、是惡魔之子、是不得擁有感情的人」。這一幕同時建立懸念與克里茲的核心創傷。 

**資訊控制／備註：**若放序幕，只剪到「惡魔之子」或舉劍；若放尾聲，可加入「媽媽，晚安」，仍不要顯示劍是否落下。

SCENE 02｜泰倫斯山黑洞：克里茲第一次遇見被視為惡魔的蕾瓦娜斯 

**★★★ 主角關係起點** 

|     |     |
| --- | --- |
| **時間／地點** | 聖曆1581年6月17日深夜，泰倫斯山・黑色洞穴內 |
| **實際出場角色** | 年幼克里茲、年幼蕾瓦娜斯 |
| **場景外角色／聲音** | 洞外風雪；聖喬治屠龍傳說可作克里茲腦中的旁白 |
| **預告片節奏** | 先 MOMENT 後 LINE；從獵殺轉為理解 |

這一幕發生什麼 

·  克里茲進入洞穴，原本以為自己遇見傳說中的惡魔，與黑暗中的生物交戰。 

·  當火光照亮對方，他看見的不是怪物，而是一名長著角與翅膀、同樣害怕他的少女。 

·  克里茲短暫想過殺死她、帶回頭顱、證明自己是英雄；最後卻放下武器，問出其實也在質問自己的話。 

可用台詞 

**克里茲內心：**「只要殺了她，像聖喬治那樣，把她的頭顱帶回去，所有人就會對我刮目相看……」 

**克里茲：**「吶……你也是一個人嗎？」 

可拆成的畫面／鏡頭 

·  洞穴只由火把與晶體微光照明，先拍角、翅膀、鎖鏈，不立刻露全臉。 

·  劍尖對準蕾瓦娜斯；她閉眼或後退。克里茲手一鬆，武器落低。 

·  兩人的金色／異色眼睛互相對望，作為關係線的第一個安靜鏡頭。 

**預告片功能：**建立蕾瓦娜斯「外表被當成惡魔、內心卻單純」的矛盾，也揭露克里茲仍有同理心。 

**資訊控制／備註：**不要在此說明她的力量與身分；只讓觀眾知道她可能是改變克里茲的人。

SCENE 03｜泰倫南部廢墟：哈努爾宣告奧德里奇已死 

**★★★ 故事主線啟動** 

|     |     |
| --- | --- |
| **時間／地點** | 聖曆1583年9月7日上午，泰倫南區森林／戰後廢墟 |
| **實際出場角色** | 克里茲、被俘的哈努爾 |
| **場景外角色／聲音** | 奧德里奇可用極短戰場閃回；遠處政變軍與火煙作背景 |
| **預告片節奏** | 資訊型 LINE，後接弒王 MOMENT |

這一幕發生什麼 

·  克里茲審問被俘的哈努爾，試圖確認父王與王國軍隊的狀況。 

·  哈努爾並不畏懼，反而帶著惡意享受克里茲的期待，直接告訴他奧德里奇已經死亡。 

·  這句話切斷克里茲仍可能等待父王回來收拾局面的希望，也為他接下王位做準備。 

可用台詞 

**哈努爾：**「奧德里奇，已經死了。」 

可拆成的畫面／鏡頭 

·  克里茲蹲在受傷的哈努爾面前，劍刃壓住他的頸側。 

·  哈努爾滿口鮮血卻笑出聲；台詞後瞬切奧德里奇倒下、王旗燃燒或空王座。 

·  克里茲沒有哭，只是瞳孔停住，讓觀眾看見他開始封閉情緒。 

**預告片功能：**這是開端最有效率的資訊台詞：父王已死、舊秩序結束、克里茲沒有退路。 

**資訊控制／備註：**不用在這一場完整解釋奧德里奇如何死亡，留到正式作品。

SCENE 04｜泰倫南部避難處：班尼迪克將聖劍與赫克托交給克里茲 

**★★★ 王位承接場** 

|     |     |
| --- | --- |
| **時間／地點** | 聖曆1583年9月7日，政變當日，泰倫南部避難據點／臨時祭壇附近 |
| **實際出場角色** | 克里茲、班尼迪克 |
| **場景外角色／聲音** | 附近難民與教會人員可在背景；奧德里奇只被提及 |
| **預告片節奏** | 莊重 LINE，間插人民逃亡 MOMENTS |

這一幕發生什麼 

·  班尼迪克確認奧德里奇已死，將象徵王權與力量的聖劍交給克里茲。 

·  他要求一名尚未準備好的少年，從此成為赫克托的新王，帶領人民尋找新家園，並在未來奪回泰倫。 

·  在託付結束前，班尼迪克補上一個更危險的警告：赫克托內部存在叛徒，而且可能就是克里茲信任的人。 

可用台詞 

**班尼迪克：**「克里茲，從現在開始，你要擔任赫克托的新王。」 

**班尼迪克：**「你要引領人民，找到新的家園，重建赫克托王國。」 

**班尼迪克：**「然後總有一天，要回到這裡，挽救這片土地的命運。」 

**班尼迪克：**「赫克托內部，有叛徒。」 

可拆成的畫面／鏡頭
