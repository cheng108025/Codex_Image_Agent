## 身份鎖定

- 銀白長髮，下段帶明亮青藍；尖耳；一對藍紫晶體長角。
- 正好一對大型銀藍半透明龍翼；銀色長尾與青藍／淡紫晶體尾尖不可省略。
- 白、銀、冰藍晶體服裝、白色腿部衣料與晶體高跟鞋保持一致。
- 後續生成應同時引用 `05` 與對應獨立視圖；圖片對臉、髮型、角、翅、尾、服裝、配色與材質具有最高優先權。
- 生成式圖片的細小晶面可能略有差異；3D 建模時以 `05` 決定輪廓，以 `07`、`09` 補足結構。
