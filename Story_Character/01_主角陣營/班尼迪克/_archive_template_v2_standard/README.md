## 身份鎖定

- 年輕纖瘦男性；淡膚色；短而柔順的紫羅蘭色波浪髮。
- 白色落地神職禮袍、淡紫垂直披帶、古金刺繡、高領與紫晶小飾件。
- 後續生成應同時引用 `05` 與對應獨立視圖；圖片對臉、髮型、服裝、配色與材質具有最高優先權。
- 生成式圖片的極小刺繡可能略有差異；3D 建模時以 `05` 決定輪廓，以 `07`、`09` 補足結構。
