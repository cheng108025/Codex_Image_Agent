## 使用注意

- `05` 是使用者指定的原始外觀正本；其他圖片是依它延伸生成的製作參考。
- 後續生成應同時引用 `05` 與 `01`，並明確鎖定臉、髮型、紅金眼、黑金服裝與紫色寶石。
- 生成式圖片在細小刺繡與扣件位置仍可能有輕微差異；進入 3D 建模前，以 `05` 決定整體輪廓，以 `07`、`09` 決定細節結構。
- 完整提示詞保存於 `PROMPTS.md`。
