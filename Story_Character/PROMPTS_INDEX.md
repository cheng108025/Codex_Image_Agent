# 角色圖片提示詞總索引（PROMPTS_INDEX）

> 依 `CLAUDE_CHARACTER_PROMPT_HANDOFF.md` 規範，為 `角色文檔.md` 全部具名角色整理的圖片生成任務包。
> 每個角色資料夾含 `CHARACTER_SPEC.md`（設定：CANON／DESIGN-PROPOSAL／PENDING-USER-INPUT 分標）
> 與 `PROMPTS.md`（英文提示詞）。**Claude 只整理提示詞，不生成圖片**；產圖交 Codex。
> 共用畫風正本：`style/STYLE_LOCK.md`（§1 正向、§2 負向、三張 style 圖僅鎖畫風不鎖身份）。

## 目錄結構（依角色文檔陣營分類）
```
output/Story_Character/
├─ style/ (三張畫風圖 + STYLE_LOCK.md)
├─ 01_主角陣營/   克里茲 皇后阿格妮絲 奧德里奇 班尼迪克 蕾瓦娜斯 高文 葛洛莉雅 艾維斯 阿爾伯特
├─ 02_反派陣營/   帕拉諾雅 馬修 托普 阿達瑪 哈努爾 巨龍
├─ 03_三大貴族/   馬爾科 艾德里 安德烈 菲利浦 賽希莉亞 伊普拉新
├─ 04_遠征士兵/   強尼 歐文 阿拉法爾特 文森特 戴夫 鮑曼
└─ 05_傳說與背景/ 聖喬治 萊拉澤爾 加爾雷斯 夜光馬
```
> 各角色資料夾內 `PROMPTS.md` 的 style 圖引用已相應改為 `../../style/`。

## 兩階段流程（每個角色都適用）
1. Codex 先只生成 `00-{slug}-character-identity-anchor.png`（正面全身＋大型正面頭肩，同一角色兩次、零漂移）。
2. 使用者核准 00 → 它成為該角色後續每張圖的 **Image 1 身份／服裝正本**。
3. 才依 `PROMPTS.md` 生成該角色其餘編號。三張 style 圖全程只鎖畫風。

## 產出統計
- 角色資料夾：**31**（全部具名角色 ＋ 2 生物），各含 `CHARACTER_SPEC.md` + `PROMPTS.md`。
- 提示詞總數：Tier S 8×10 ＝ 80；Tier A 11×3 ＝ 33；Tier B 10×1 ＝ 10；Creature 2×1 ＝ 2。**合計 125 條**。
- 全部逐字沿用 `style/STYLE_LOCK.md` §1／§2，並依角色追加專屬互斥負向詞（人類排除翼/角/尾；蕾瓦娜斯/阿達瑪等保留其非人正典特徵）。

## 已套用的一致性修正（v2，全 31 角色）
對照三張範例圖（2048×672 ≈ 3:1）逐項補強，規則正本見 `style/STYLE_LOCK.md` §5–§8：
1. **身份鎖定**：辨識關鍵的瞳色/髮色/紋章/性別年齡全部鎖成 00 具體預設值，各 SPEC 附「鎖定錨定預設值（可覆蓋）」——模型不再隨機決定。
2. **畫布比例**：00＝左55%全身＋右45%大頭肩（臉佔≥60%）、約3:1；05＝3:1 超寬橫幅、四人一排等尺不裁切。
3. **防複製範例**：每張負向詞排除克里茲黑金肩甲/鏈/紫寶石、蕾瓦娜斯冰晶角翼尾、白金神職袍、範例臉；三張圖只鎖光影/線稿/材質。各角色**保留自身正典**（馬修神職袍、蕾瓦娜斯角翼、阿達瑪結晶、生物的尾）。
4. **材質對齊**：每角色明寫實際主材質、負向排除不該有的材質。

## 仍待使用者定案（各 SPEC 的少數 PENDING，皆有可用預設值、非阻塞）
- 各角色的**鎖定預設值可覆蓋**（若你對某人瞳色/髮色/紋章有指定，核准 00 時提出即可）。
- 三大家族**家紋圖樣**已各給程式化預設（獒犬獠牙頭／三瓣鳶尾／五裂梧桐葉），可再精修。
- 圖與文檔衝突一律**以現有圖為外觀正本**（例：克里茲＝紅金瞳；奧德里奇瞳色刻意區別於克里茲金瞳）。
